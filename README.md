# ZOCO: APAGÓN

Demo de shooter en primera persona en el navegador (Three.js + postprocessing + N8AO).
Una discoteca inspirada en la sala grande de la Salamandra (L'Hospitalet) durante un apagón.

- `npm run dev` para desarrollo, `npm run deploy` para publicar en GitHub Pages (rama `gh-pages`).
- Texturas CC0 de Poly Haven en `public/tex`. Soldier.glb de los ejemplos de three.js.
